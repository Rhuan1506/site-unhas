# Flávia Souza Nail Designer

Sistema de agendamento online desenvolvido para uma profissional da área de Nail Design, permitindo que clientes visualizem serviços, consultem preços e realizem agendamentos diretamente pelo WhatsApp.

##  Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- WhatsApp API

##  Funcionalidades

- Catálogo de serviços
- Tabela de preços
- Seleção de serviço automática
- Escolha de data e horário
- Integração com WhatsApp
- Links para redes sociais
- Layout responsivo


##  Objetivo do Projeto

Desenvolver uma solução prática para agendamento de clientes, aplicando conceitos de HTML, CSS e JavaScript em um cenário real.
